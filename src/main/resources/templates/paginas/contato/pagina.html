De onde vêm os dados

Todas as fontes em uso são abertas e sem chave de API. Isso não é detalhe de implementação: significa que este sistema continua funcionando sem cadastro, sem cota e sem uma credencial que possa vazar.

Fontes de dados, o que fazem, e o que mudou em relação ao projeto original.
Fonte Para quê Chave Situação
NASA EONET v3 Os eventos naturais que disparam o alerta Não exige Mantida do projeto original
BrasilAPI CEP Endereço a partir do CEP, já com coordenada Não exige Nova — é a mais rápida e a única que devolve coordenada junto
ViaCEP Endereço pelo CEP, quando a primeira não responde Não exige Mantida, agora como reserva
Nominatim / OpenStreetMap Coordenada quando o CEP não a traz Não exige Substituiu o Google Geocoding
GDACS (ONU / UE) O noticiário de desastres da página inicial Não exige Substituiu a ReliefWeb, que foi desativada
Duas fontes do projeto original não estão aqui, e vale dizer por quê.
  • Google Geocoding exigia chave de API e cobrança por uso. Foi trocada pelo Nominatim, que é aberto — e a chave que o projeto original carregava não deve mesmo continuar viva.
  • ReliefWeb foi desativada: a versão 1 da API responde HTTP 410 e a versão 2 exige um identificador de aplicação previamente aprovado. Medido em 02/09/2026 — o carrossel de notícias do projeto original não funciona mais, e não é por causa desta reconstrução.
